一、软件概述
1.1 软件简介
本软件名称为食安雷达食品配料智能分析系统V1.0。系统以微信小程序为主要使用入口，围绕食品配料表识别、食品安全分析、风险提示和个性化健康建议等功能展开，面向家庭日常食品管理场景提供辅助分析服务。
软件名称中的“食安雷达”体现了系统对食品安全风险的快速识别与提醒能力，“食品配料智能分析系统”则概括了系统围绕配料表开展识别、判断、评分和解读的核心定位。V1.0 版本表示该软件已经具备完整的基础功能和主要业务流程，可独立完成从图片识别到结果展示的主要操作。
1.2 开发背景与用途
随着消费者对食品安全问题的关注不断提升，食品包装上的配料表逐渐成为判断食品是否适合食用的重要依据。但配料名称往往较为专业，普通用户在面对添加剂名称、营养成分、人群禁忌和食品类别时，通常难以快速判断其风险程度。为解决这一问题，本系统通过图像识别、规则分析和智能问答等方式，将复杂的配料信息转化为更容易理解的健康评分和风险提示，帮助用户更高效地做出食品选择。
本软件主要用于日常食品选购参考、家庭成员饮食管理、食品添加剂知识查询以及食品对比分析。用户可通过小程序拍照或上传配料表图片，系统自动识别并分析食品内容，同时结合用户人群类型和忌口偏好生成个性化建议，从而提升食品安全管理的便捷性和实用性。
1.3 运行环境
本系统采用前后端分离架构运行，前端运行于微信小程序环境，后端运行于 Python 3.14.4 与 Flask 服务环境，并配合 MySQL 数据库和 SQLAlchemy ORM 完成数据存储与访问。开发系统采用 Windows 11，开发工具包括微信开发者工具、Visual Studio Code 等。系统部署后，可运行于 Windows 或 Linux 服务器环境，并通过微信客户端直接向用户提供服务。
运行环境可概括如下：
开发语言：JavaScript、Python 3.14.4
前端环境：微信小程序、微信开发者工具
后端环境：Flask Web 服务
数据库环境：MySQL
部署环境：Windows / Linux 服务器
外部接口：百度 OCR 接口、DeepSeek 风格 AI 接口
1.4 软件功能概览
本系统主要由食品扫描分析、食品对比、扫描历史、健康档案、家庭成员管理、添加剂百科查询和 AI 营养问答等功能组成。用户在首页即可进入核心扫描流程，通过拍照识别食品配料表后，系统自动生成健康评分、风险添加剂列表、建议说明和人群预警信息，帮助用户快速理解食品风险。除核心分析功能外，系统还支持家庭成员档案管理、个性化忌口设置、食品对比分析、历史记录查看和趋势统计等功能。对于不熟悉食品添加剂名称的用户，系统还提供百科查询与 AI 问答能力，帮助用户进一步理解食品成分和饮食建议。整体上，软件形成了“识别-分析-记录-建议-管理”的完整闭环。
二、快速开始
2.1 进入与其用
用户可通过微信客户端打开食安雷达食品配料智能分析系统V1.0。进入小程序后，系统会加载首页资源，并检查本地是否已存在用户档案或家庭成员信息。如果用户已经完成过基础设置，系统会直接进入首页；如果是首次使用，系统会引导用户先建立个人档案，以便后续分析结果能够结合用户身份和健康偏好进行展示。
2.2 首页界面说明
用户进入首页后，可以查看当前成员的食品安全评分、近期扫描记录、风险摘要、趋势提示以及常用功能按钮。首页底部提供主要导航入口，包括首页、档案、识别、探索和我的等模块，方便用户快速切换到不同功能页面。
2.3 首次使用配置
首次使用时，用户应尽量完整填写基础档案，尤其是人群类型和忌口偏好，这些信息会影响系统后续的风险提示和建议内容。如果暂时不想填写详细资料，也可以先使用默认普通人群身份，后续再进入个人中心或家庭成员管理页面进行修改。
首次使用时还应注意，本系统提供的分析结果主要用于日常食品风险参考，不替代医学诊断、营养处方或监管结论。对于疾病治疗、严重过敏或特殊医学饮食需求，用户仍应咨询专业医生或营养师。
三、功能适用
3.1 食品扫描识别
食品扫描与分析是本系统最核心的功能。用户可从相册中上传已有图片，系统会自动将图片提交至后端进行处理。
3.2 分析结果查看
识别完成后，系统会自动生成分析结果页面。页面中会显示食品健康分、风险成分列表、有益成分提示、人群预警信息以及 AI 生成的建议内容。
用户可在该页面查看系统对当前食品的完整分析，包括主要风险成分、是否命中个人忌口、是否触发特殊人群预警，以及 AI 生成的说明和建议。页面设计的重点是让复杂的识别结果变得直观、可读、可比较。
在结果页中，用户还可以进一步查看成分详情、跳转到添加剂百科、返回首页继续扫描，或将当前结果与其他食品进行比较。该页面相当于整个扫描流程的“结论页”，不仅展示结果，也承接后续的对比、历史记录和知识查询操作，是用户理解食品风险的核心页面之一。
3.3 扫描历史管理
系统会在用户完成食品扫描分析后，将本次识别结果保存为扫描历史记录。历史记录通常包括食品分类、健康评分、高风险添加剂数量、扫描时间以及完整分析结果等信息。用户可以在历史页面中查看近期扫描过的食品，并通过记录进入对应的分析详情页，便于后续回顾和对比。
3.4 食品对比
用户可以分别选择两张食品配料表图片，系统会对两款食品分别进行识别、分类、评分和风险分析，然后从健康评分、风险成分数量、有益成分数量、人群提醒等方面进行对比。系统会根据综合结果给出更推荐的食品，并展示两款食品的差异。通过对比功能，用户可以更直观地看到哪一款食品添加剂更少、风险项更低、是否更适合当前家庭成员。系统还可生成简短的 AI 对比建议，帮助用户理解推荐原因。
3.5 健康趋势
系统会根据用户的扫描历史记录生成一定程度的健康趋势信息。例如，首页和档案页面会展示近期扫描次数、平均健康评分、风险提示和趋势摘要。当用户积累多次扫描记录后，系统可以根据最近记录计算平均分，并判断食品选择是否趋于稳定、是否存在高频风险成分或低分食品。
3.6 添加剂百科查询
系统提供添加剂百科查询功能，用户可以在“探索”或“添加剂百科”页面中查看常见食品添加剂信息。
百科内容通常包括添加剂名称、别名、分类、主要用途、常见食品、风险等级、注意事项和特殊人群提示等内容。用户在查看食品分析结果时，也可以点击风险成分名称进入百科详情页面，进一步了解该成分的作用和风险。
3.7  AI营养师问答
系统内置 AI 营养师问答功能，用户可以围绕食品安全、配料表、食品添加剂、营养选择和特殊人群饮食风险等问题进行提问。AI 问答功能会结合用户问题生成自然语言回答，帮助用户理解较复杂的食品安全知识。
AI 营养师问答主要用于补充固定规则无法覆盖的解释类场景。它并不替代医生或专业营养师的诊断意见，而是作为日常食品选择时的辅助说明工具。系统在回答时会尽量使用通俗表达，减少过多专业术语，让用户能够更容易理解食品配料和营养风险。
3.8 用户画像
个人中心用于展示当前用户或当前家庭成员的基础画像信息。系统会根据档案中保存的昵称、头像、人群类型、年龄、性别、身高、体重和忌口偏好等内容，形成当前成员的个人视图。用户可以在这里快速查看自己的基础资料，也可以了解系统当前是按照哪一类人群进行食品分析。
3.9 资料管理
(1)家庭成员管理
本系统支持家庭成员管理，用户可以根据实际使用场景添加多个家庭成员，并为每位成员建立独立档案。每个成员档案可包含昵称、家庭关系、性别、年龄、身高、体重、头像和人群类型等信息，方便系统在分析食品时区分不同对象。这样一来，系统不仅可以服务“我自己”，也可以服务家庭中的儿童、老人、孕妇或其他需要特殊关注的人群。
在使用过程中，用户可在家庭成员之间切换，系统会自动读取当前选中的成员信息，并将扫描历史与该成员关联保存。这样，用户在查看历史记录、食品对比结果或健康趋势时，能够清楚地区分不同家庭成员的食品安全情况。家庭成员管理功能使系统更适合家庭场景，也为后续的个性化分析提供了基础数据。
(2) 人群类型与忌口设置
系统为每位成员提供人群类型设置功能，常见类型包括普通人群、儿童、老人、孕妇、糖尿病、心血管、减肥和健身等。不同人群对应不同的饮食关注点，系统会根据人群类型自动调整分析结果中的预警重点，使提示更有针对性。
同时，用户还可以设置个人忌口偏好，包括过敏类、不耐受类和主动回避类成分。系统在分析食品时，如果识别到这些成分，会在结果中进行提示，帮助用户避免误食不适合的食品。
(3) 基础资料修改
个人中心支持用户对基础资料进行管理和修改。用户可在需要时更新昵称、性别、年龄、身高、体重、头像，也可以进入家庭成员管理页面添加或切换成员。资料管理功能还支持对历史信息进行同步调整，保证用户在长期使用中能够持续获得匹配自身情况的结果。
四、使用帮助
4.1 识别问题处理
为提高配料表识别准确率，用户在拍摄食品包装时，应尽量对准配料表区域进行拍摄。图片中应包含完整、清晰的“配料”“配料表”“成分”或“原料”等文字内容，避免只拍摄品牌名称、正面包装、营养成分表或生产日期区域。拍摄时建议保持光线充足，避免反光、阴影、模糊和严重倾斜。如果食品包装表面较弯曲或字体较小，建议用户将包装尽量展开，并让手机镜头靠近配料表区域。对于文字较密集的包装，可以优先保证配料表文字清晰，而不必完整拍下整个包装。清晰的图片有助于OCR接口准确识别文字，也能减少后续配料提取和分析中的误差。
当系统提示识别失败或未找到有效配料表时，通常可能由图片模糊、光线不足、未拍到配料表、拍到营养成分表或包装文字过于复杂等原因造成。用户可以重新拍摄配料表区域，从相册中选择更清晰的图片再次识别。若包装中配料表位置较隐蔽，用户应先找到包含配料文字的区域，再进行拍摄。
4.2 数据与隐私
本系统在使用过程中会保存部分必要的本地数据，用于支持用户档案、家庭成员切换、扫描历史查看和结果回溯等功能。保存的数据主要包括用户昵称、头像、人群类型、忌口设置、扫描记录和最近分析结果等，不涉及与食品分析无关的多余信息。系统保存这些数据的目的，是为了方便用户下次使用时快速恢复上次状态，并持续生成个性化分析结果。
在隐私保护方面，系统仅在完成分析和历史管理所必需的范围内处理用户数据。用户可通过清除缓存、删除成员或重置资料等方式主动管理本地信息。系统不会要求用户提供与食品分析无关的敏感信息，分析内容也主要用于日常食品安全参考，不作为医疗诊断依据。
4.3 使用注意事项
本系统提供的食品安全分析结果主要用于日常食品选择参考，不能替代医学诊断、营养处方或监管部门结论。系统中的健康评分、风险提示和 AI 建议，均基于识别到的配料信息、知识库规则和当前用户档案生成，结果会受到图片质量、配料表完整性和识别准确率影响。
对于严重过敏、特殊疾病饮食、孕婴食品选择、药物相关饮食限制等高风险场景，用户应优先咨询医生、营养师或参考权威标准。系统可帮助用户提高对配料表的理解效率，但最终食品选择仍需结合个人身体状况、摄入频率和实际生活习惯综合判断。
